# Light Meter App Icons

## Icon Design

The Light Meter Pro icon is designed to be immediately recognizable as a photography/metering tool while maintaining visual clarity at all sizes.

### Design Elements

**Main Visual:** Professional light meter reticle
- **Dual circles** - Represent spot metering zones
- **Center dot** - Focus point indicator
- **Crosshairs** - Professional measurement targeting
- **Corner brackets** - Viewfinder framing elements

**Color Scheme:**
- **Primary:** Bright cyan/green (#00ff88) - High visibility, tech-forward
- **Background:** Dark charcoal (#0a0a0a) - Professional, reduces eye strain
- **Subtle gradient** - Adds depth without clutter

### Technical Details

**Standard Icons:**
- `icon-192.png` - For most platforms
- `icon-512.png` - High-resolution displays

**Maskable Icons (Android Adaptive):**
- `icon-192-maskable.png` - Ensures full visibility in any Android shape (circle, square, squircle)
- `icon-512-maskable.png` - High-res adaptive icon

### Why This Design?

✓ **Instantly recognizable** - Clear light meter/camera imagery  
✓ **Professional aesthetic** - Matches the app's serious photography focus  
✓ **High contrast** - Stands out on any home screen background  
✓ **Scales well** - Readable from tiny (48px) to large (512px)  
✓ **Unique** - Doesn't look like generic camera/photo apps  
✓ **Brand consistent** - Matches the app's UI design language  

## Home Screen Appearance

The icon will appear on your home screen with:
- Clear, bright targeting reticle
- Professional photography tool aesthetic
- High visibility in both light and dark themes
- Adaptive shape on Android (circle, square, rounded square, etc.)

## Favicon

The same icon design is used for browser tabs and bookmarks, maintaining brand consistency across all platforms.
